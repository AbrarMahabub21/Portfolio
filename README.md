# Portfolio

My personal portfolio website, built with React and Vite. It has sections for about me, experience, tech skills, projects and a contact form, with some 3D models made with Three.js.

## Stack

- React 18 and Vite
- Tailwind CSS
- Three.js with React Three Fiber
- Framer Motion for animations
- EmailJS for the contact form

## Run it locally

1. Install packages:
   ```
   npm install
   ```
2. Copy `.env.example` to `.env.local` and add your own EmailJS service ID, template ID and public key.
3. Start the dev server:
   ```
   npm run dev
   ```
4. Build for production with `npm run build`.
